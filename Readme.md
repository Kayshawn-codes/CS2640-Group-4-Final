Cornerstone Finance is a simple banking application written in MIPS assembly language.

The program allows the user to:
- Create a new account
- Log in with an existing username and password
- View account menu
- Store information related to the account in a text file

## Requirements
To use this program, Java Runtime Environment must be installed.

## Setup



- Clone the repo from Github (sudo git clone https://github.com/Kayshawn-codes/CS2640-Group-4-Final.git) to whatever folder you wish. 
- Open a terminal window and use the "java -jar" command to open MARS.
- Import the files into MARS.
- Assemble the program by clicking the "Assemble"

## Navigating the Program

- Type in the corresponding number for whatever option you want.
    (1 for Log In, 2 for Sign Up, and 3 for Exit)

- **Sign Up**
- Choose Option 2.
- Enter first & last name, username and password.


- **Log In**
- Choose Option 1.
- Enter Username & Password


- **User Menu**
- Press option to view account, logout, etc.

- **Exit**
-Press Option 3 from the menu to exit the program.
